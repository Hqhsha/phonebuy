# PhoneBuy — Android

Native Android implementation of the PhoneBuy phone-reselling game.

## Build APK

The repository uses Gradle and GitHub Actions to build a debug APK. Open the repository's **Actions** tab, run **Android APK**, and download the `PhoneBuy-debug-apk` artifact from the completed workflow.

## Game

Buy used phones, inspect defects, bargain, repair, list for sale, accept buyer offers, manage bank debt, complete quests, and grow your capital. Game state is stored locally on the device.
